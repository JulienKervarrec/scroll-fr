# 8. Limites et périmètre

Ce parcours couvre le monorepo Scroll, le flux rollup-lots, les circuits zkEVM, les tâches de prover, le coordinator, la persistance, le pont L1/L2, les RPC et l’observabilité.

Il ne constitue ni un audit, ni une preuve de validité des paramètres réseau, ni une validation des déploiements. Le dépôt comprend de nombreux composants et dépendances externes qui demandent une étude dédiée.

La lecture a porté sur le README, les dossiers rollup, coordinator, prover, database, common et crates. Aucune installation, compilation, exécution de test ou transaction n’a été effectuée. Consultez les tests du dépôt pour poursuivre.
